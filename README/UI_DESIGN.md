# 装甲板识别系统UI设计文档

## 1. 概述

本文档详细介绍了装甲板识别系统的用户界面设计，包括参数调节面板的布局、组织结构和使用方法。UI设计旨在提供直观、易用的参数调节体验，帮助用户快速调整识别参数以适应不同的环境条件。

## 2. 主要窗口

系统包含两个主要窗口：

1. **主显示窗口** (`Armor Detection`) - 显示摄像头画面和识别结果
2. **参数调节窗口** (`Armor Parameters`) - 提供参数调节滑动条

## 3. 参数调节窗口设计

### 3.1 设计原则

- **分组清晰**：相关参数归为一组，便于查找和调节
- **标签明确**：每个滑动条都有明确的功能说明
- **视觉提示**：使用颜色标识和缩写提示参数类型
- **逻辑排序**：按照处理流程排列参数组

### 3.2 界面布局

参数调节窗口采用分层分组设计，从上到下依次为：

#### 顶部说明区域
- UI使用指南
- 参数缩写说明

#### 1. 相机参数组 (Camera Parameters)
调节相机硬件相关参数：
- 曝光时间 (Exposure Time)：控制相机快门速度，范围1-100000微秒
- 红色增益 (Red Gain)：调节红色通道敏感度
- 绿色增益 (Green Gain)：调节绿色通道敏感度
- 蓝色增益 (Blue Gain)：调节蓝色通道敏感度

#### 2. 红色阈值组1 (Red Color Thresholds 1)
调节红色装甲板HSV颜色阈值的第一组范围：
- 色调低值 (H Low)：红色色调最小值 (0-180)
- 饱和度低值 (S Low)：红色饱和度最小值 (0-255)
- 明度低值 (V Low)：红色明度最小值 (0-255)
- 色调高值 (H High)：红色色调最大值 (0-180)
- 饱和度高值 (S High)：红色饱和度最大值 (0-255)
- 明度高值 (V High)：红色明度最大值 (0-255)

#### 3. 红色阈值组2 (Red Color Thresholds 2)
调节红色装甲板HSV颜色阈值的第二组范围（由于红色在HSV空间横跨0°和180°）：
- 色调低值 (H Low)：红色色调最小值 (0-180)
- 饱和度低值 (S Low)：红色饱和度最小值 (0-255)
- 明度低值 (V Low)：红色明度最小值 (0-255)
- 色调高值 (H High)：红色色调最大值 (0-180)
- 饱和度高值 (S High)：红色饱和度最大值 (0-255)
- 明度高值 (V High)：红色明度最大值 (0-255)

#### 4. 蓝色阈值组 (Blue Color Thresholds)
调节蓝色装甲板HSV颜色阈值：
- 色调低值 (H Low)：蓝色色调最小值 (0-180)
- 饱和度低值 (S Low)：蓝色饱和度最小值 (0-255)
- 明度低值 (V Low)：蓝色明度最小值 (0-255)
- 色调高值 (H High)：蓝色色调最大值 (0-180)
- 饱和度高值 (S High)：蓝色饱和度最大值 (0-255)
- 明度高值 (V High)：蓝色明度最大值 (0-255)

#### 5. 轮廓过滤组 (Contour Filtering)
调节轮廓检测的过滤参数：
- 最小面积 (Min Area)：轮廓最小像素面积
- 最大面积 (Max Area)：轮廓最大像素面积

#### 6. 装甲板匹配组 (Armor Matching)
调节装甲板灯条匹配参数：
- 最小距离 (Min Distance)：两个灯条间的最小像素距离
- 最大距离 (Max Distance)：两个灯条间的最大像素距离
- 最大角度差 (Max Angle Diff)：两个灯条间的角度差阈值

#### 7. 预设曝光组 (Preset Exposures)
设置三种环境条件下的预设曝光参数：
- 明亮环境 (Bright Preset)：明亮环境下的曝光时间
- 正常环境 (Normal Preset)：正常光照下的曝光时间
- 黑暗环境 (Dark Preset)：黑暗环境下的曝光时间

#### 8. 游戏控制组 (Game Control)
调节比赛相关的控制参数：
- 识别模式 (Recognition Mode)：
  - 0: 准备阶段
  - 1: 第一次识别
  - 2: 第二次识别

#### 底部提示区域
- UI使用技巧
- 快捷键提示

### 3.3 视觉标识说明

为了便于识别不同类型的参数，滑动条标签中包含了以下标识：

- `[H]` - 色调 (Hue) 参数
- `[S]` - 饱和度 (Saturation) 参数
- `[V]` - 明度 (Value) 参数
- `[R]` - 红色通道增益
- `[G]` - 绿色通道增益
- `[B]` - 蓝色通道增益

## 4. 使用指南

### 4.1 参数调节流程

1. **调节相机参数**：
   - 根据环境光照条件设置合适的曝光时间
   - 调整RGB增益以优化色彩表现

2. **调节颜色阈值**：
   - 先调节红色阈值组1和组2，使红色装甲板在二值化图像中清晰可见
   - 再调节蓝色阈值，使蓝色装甲板在二值化图像中清晰可见

3. **调节轮廓过滤参数**：
   - 设置合适的面积范围，过滤掉过小或过大的噪点

4. **调节匹配参数**：
   - 根据实际装甲板尺寸调整距离参数
   - 根据安装角度调整角度差参数

5. **设置预设参数**：
   - 为不同光照条件设置合适的预设曝光值

### 4.2 快捷键操作

- **1键**：应用明亮环境预设
- **2键**：应用正常环境预设
- **3键**：应用黑暗环境预设
- **P键**：保存当前所有参数为预设配置

### 4.3 最佳实践

1. **初始设置**：
   - 在开始调节前，先使用快捷键设置适合当前环境的预设曝光
   - 观察二值化图像显示（按B键切换），确保装甲板灯条清晰可见

2. **逐步调节**：
   - 一次只调节一个参数组，观察效果变化
   - 小幅度调整，避免参数跳跃变化

3. **参数保存**：
   - 调节满意后按P键保存参数
   - 参数将保存到params.xml文件，下次启动时自动加载

## 5. UI设计改进计划

### 5.1 当前版本特性

- 分组清晰的滑动条布局
- 颜色标识帮助识别参数类型
- 实时参数调节反馈
- 预设参数快速切换

### 5.2 未来改进方向

1. **增加数值显示**：
   - 在滑动条旁边显示当前数值
   - 提供数值输入框进行精确调节

2. **增加重置功能**：
   - 为每个参数组提供重置按钮
   - 提供全部参数重置功能

3. **增加可视化辅助**：
   - 实时显示HSV颜色范围
   - 显示轮廓过滤效果预览

4. **界面自适应**：
   - 根据屏幕分辨率自动调整界面布局
   - 支持窗口大小调整

通过以上设计，装甲板识别系统的UI能够为用户提供直观、高效的参数调节体验，帮助用户快速适应不同环境条件并获得最佳识别效果。
