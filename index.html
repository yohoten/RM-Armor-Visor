01 / FEATURES

功能特性

从图像采集到坐标输出的全链路实现，并针对赛场实时性做了工程化取舍。

◈ 01

红 / 蓝双色实时识别

红色因 HSV 色环跨 0° 与 180° 采用双区间合并掩膜，蓝色使用单区间，支持同帧多目标。

◈ 02

中心坐标解算

输出装甲板中心像素坐标、包围盒尺寸与相对画面中心的偏移量，直接供云台控制系统消费。

◈ 03

自绘 HUD 可视化

暗角、扫描线、八分刻度准星、角括号锁定框与信息卡实时叠加，并使用静态层缓存降低重绘开销。

◈ 04

拖拽式参数面板

自绘 380px 控制面板，分区管理曝光 / 增益 / HSV 阈值 / 形状过滤，支持分区折叠与鼠标拖拽调参。

◈ 05

ROI 靶面跟踪

以上帧最优目标为中心外扩 3×2 形成 ROI，仅在局部区域检索；连续 300 帧丢失即恢复全画面。

◈ 06

自适应帧率策略

按平滑 FPS 自动切换：<40 启用简化流程并跳帧，<67 隔帧处理，高帧率全量处理。

◈ 07

相机曝光预设

明亮 / 正常 / 黑暗三档快门预设，一键切换以适应不同场馆光照，配套 RGB 增益手动微调。

◈ 08

YAML 参数持久化

基于 cv::FileStorage 读写 preset_*.yaml，调试好的整套参数可存档并在启动时载入。

◈ 09

录像与抓帧

内建 MP4 录像（avc1）与 PNG 截图，带时间戳自动命名，便于赛后复盘与数据集采集。

◈ 10

无相机降级运行

摄像头缺失时进入 Demo 模式并每 2 秒尝试重连，界面与全部控件保持可用，便于离线调试。

// 灯条筛选 —— fitEllipse + 凸性(solidity)，参考 SEU 方案改进
bool ImageProcessor::isLightBar(const std::vector<cv::Point>& contour) {
    double area = cv::contourArea(contour);
    if (area < filter.min_area || area > filter.max_area) return false;

    if (contour.size() < 5) return false;              // fitEllipse 至少 5 点
    cv::RotatedRect rect = cv::fitEllipse(contour);
    adjustRect(rect);                              // 归一化角度到 [-45,45]

    // solidity = 轮廓面积 / 椭圆面积，灯条应当足够充实
    double ellipse_area = CV_PI * rect.size.width * rect.size.height / 4.0;
    if (ellipse_area < 1.0) return false;
    double solidity = area / ellipse_area;
    if (solidity < 0.4 || solidity > 1.8) return false;

    float hw_ratio = rect.size.height / std::max(1.0f, rect.size.width);
    if (hw_ratio < filter.min_ratio || hw_ratio > filter.max_ratio) return false;
    return true;
}
▣ 配对约束

装甲板几何判据

  • 角度差 < 7°（简化模式放宽至 15°）
  • 灯条高度差比 < 0.20
  • 纵向错位 yDiff / mean_h < 2.0
  • 横向间距比 dist / mean_h ∈ [1.0, 5.0]
  • 且 xDiff > yDiff，横向排布优先
  • 每个左灯条仅取首个有效配对（内置 NMS）
▣ 评分函数

最优目标决策

综合 尺寸、居中程度 与 置信度 三项加权，选出得分最高的目标移至队首，并据此更新跟踪 ROI。

score = exp(area/1500)
       + exp(-norm(center-frame_center)/250)
       + confidence * 3.0
03 / BUILD

快速开始

依赖极少：一个支持 C++11 的编译器、CMake 3.10+ 与 OpenCV 4.x。以下两条命令即可产出可执行文件。

PowerShell一键构建
# build.ps1 — 使用 MSYS2 MSVCRT GCC 构建（MinGW Makefiles）
$env:PATH = "C:\msys64\mingw64\bin;$env:PATH"
cmake -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -B build -S .
mingw32-make -C build -j4

# run.ps1 — 未构建则自动构建后启动
.\run.ps1
CMake GUI 路径OpenCV_DIR 必须显式指定
mkdir build
cmake .. -DOpenCV_DIR="C:/opencv/build/x64/vc15/lib"   # MSVC
cmake .. -DOpenCV_DIR="H:/OpenCV-MinGW-Build-OpenCV-4.5.2-x64"  # MinGW
cmake --build . --config Release

注意：务必把 OpenCV 的 bin 目录加入 PATH，否则运行时会因缺少 DLL 而直接退出。 使用构建脚本时，CMake 已配置 POST_BUILD 自动拷贝 OpenCV 及 MinGW 运行时 DLL 到输出目录。

Bashapt 安装依赖
sudo apt-get update
sudo apt-get install build-essential cmake git libopencv-dev
Bash构建 & 运行
mkdir -p build && cd build
cmake -DOpenCV_DIR="path/to/opencv" ..
make -j$(nproc)

控制面板分区

分区可调项作用
CAMERAExposure · Gain曝光量 0–2000、增益 0–100。低曝光是屏蔽环境光的第一步。
RED ARMORH Width · S/V Min红色阈值的色相跨度与饱和度 / 明度下限。

◈ 吞吐

队列与内存

处理队列上限 5 帧，队列满时丢弃旧帧而非阻塞；图像处理以移动语义传递，避免频繁 clone。

◈ 并发

线程协作

采集 / 处理 / 渲染三线程，条件变量 + 原子变量同步，退出时先置标志再 notify 回收。

◈ 降级

自适应处理

FPS 低于阈值切换到 minAreaRect 简化链路（固定 3×3 核、单次 OPEN），并放宽几何约束保帧率。

◈ 度量

FPS 统计

10 次滑动平均 + EMA 平滑双重处理，数值基于实际处理耗时而非单纯计数，避免抖动。
